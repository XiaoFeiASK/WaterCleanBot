# 部署检查清单

在预发或生产部署前使用此清单。

## 预发环境

- 环境变量已在 Git 之外配置。
- PostgreSQL/PostGIS 能够成功启动。
- 所有迁移都能从空数据库开始执行。
- 种子数据仅限开发或预发环境使用。
- 后端和测试机器人客户端都能访问 MQTT 消息代理。

## 生产环境

- PostgreSQL 的 5432 端口未暴露到公网。
- API 使用 HTTPS。
- MQTT 在 8883 端口使用 TLS。
- 已配置机器人凭据和 ACL 规则。
- 数据库备份已成功运行。
- 已在隔离环境测试备份恢复。
- 已启用日志和基础告警。
