# 架构

本文档说明平台第一个可部署版本的形态。

```text
机器人 -> MQTT 消息代理 -> Go 后端 -> PostgreSQL/PostGIS
                                 |
                                 -> 管理看板 API
```

## 组件

- 机器人固件发布遥测，并订阅命令主题。
- MQTT 消息代理负责路由遥测、命令和确认消息。
- Go 后端校验消息并写入 PostgreSQL。
- PostgreSQL/PostGIS 存储业务数据、历史遥测和空间数据。
- 管理看板调用 Go 后端暴露的 HTTPS API。

## 首版规则

首版保持为一个 Go 后端服务。在遥测链路和运维需求得到验证前，不拆分微服务。
